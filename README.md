# WatchFlix

WatchFlix is a full-stack movie streaming platform built as a database project. The application manages movies, viewing versions, actors, clients, watch history, votes, reviews, predefined reactions, personalized recommendations, sentiment analysis, and seasonal viewing predictions.

The main goal of the project is to keep the important analytical logic at database-server level. PostgreSQL procedures, functions, and triggers are used for rating recalculation, sentiment detection, client profiles, recommendations, and seasonal predictions.

## Features

- Movie catalog with title, description, category, release date, poster, and calculated rating.
- Multiple movie versions by resolution, language, format, and availability.
- Actor management and actor pages with movies from the database.
- Client authentication and profile data management.
- Complete watch history by client, movie, version, date, duration, and status.
- Voting system with one vote per client and movie.
- Review system with SQL-based sentiment analysis.
- Predefined reaction options such as `interesant`, `emotionant`, `plictisitor`, `actor principal apreciat`, and `scenariu slab`.
- Personalized recommendations generated by PostgreSQL logic.
- Seasonal predictions for periods such as holidays, summer vacation, Halloween, and February.
- Project documentation and DBML schema for dbdiagram.io.

## Database Setup

Create a PostgreSQL database, for example:

```sql
CREATE DATABASE filme_db;
```

Then run the SQL scripts in this order:

```text
WatchFlix-Backend/DatabaseScripts/SQL/databaseCreation.sql
WatchFlix-Backend/DatabaseScripts/SQL/Procedures.sql
WatchFlix-Backend/DatabaseScripts/SQL/Triggere.sql
```

If you already have an older version of the database, `Procedures.sql` includes `DROP FUNCTION IF EXISTS` / `DROP PROCEDURE IF EXISTS` statements so it can be rerun safely for the database routines.

Optional population scripts are available in:

```text
WatchFlix-Backend/DatabaseScripts/
```

The project uses TMDB-style movie data files included in the backend database scripts folder.

## Backend Configuration

Database connection settings are in:

```text
WatchFlix-Backend/src/main/resources/application.properties
```

Default local configuration:

```properties
spring.datasource.url=jdbc:postgresql://localhost:5432/filme_db
spring.datasource.username=postgres
spring.datasource.password=password
server.port=8080
```

Change the username and password to match your local PostgreSQL setup before running the backend.

## Important Database Logic

### Rating Recalculation

Movie ratings are recalculated at database level when votes are inserted, updated, or deleted.

Relevant object:

```text
fn_recalculeaza_rating
trg_recalculeaza_rating
```

### Sentiment Analysis

Review sentiment is detected in PostgreSQL using keyword and phrase matching. The resulting value is stored as:

```text
POZITIV
NEGATIV
NEUTRU
```

Relevant object:

```text
fn_analiza_sentiment
trg_analiza_sentiment
```

### Recommendations

Recommendations are generated by a stored procedure. The score is based on:

- watched categories;
- frequently watched actors;
- votes and ratings;
- comment sentiment;
- predefined client reactions;
- general popularity.

Relevant object:

```text
genereaza_recomandari(p_id_client)
```

### Seasonal Predictions

The seasonal prediction function estimates which movies may be watched more often during selected periods. The score uses:

- historical views in the selected months;
- category popularity;
- actor popularity;
- ratings;
- comment sentiment;
- predefined reaction options.

Relevant object:

```text
get_predictii_sezoniere(p_luna_start, p_luna_end, p_limit)
```
